# Finder Tools catalogue

Read README.md, docs/PROJECT_CONTEXT.md, docs/HANDOFF.md and docs/REVIEW_WORKFLOW.md. This is public descriptions and icons only. Never copy toolkit source, installers, macros, personal settings, facility templates or credentials here. Source development belongs in the existing private toolkit repository.

Preserve entries and icons. Make scoped task-branch changes, run python3 tools/check_catalogue.py, and record actual results. Ask before push/merge or changing repository settings. Do not run desktop apps or installers for catalogue validation.

## Code Review Rules

Reject private-data/source exposure, broken icon references and unsupported app claims. Catalogue checks establish structure only, not desktop utility correctness.

For day-to-day agent use, read docs/USING_AGENTS.md. Development implementation remains separate; no private development handoffs belong in this public catalogue.
